# Jev——一次值得赞颂的挣扎，我能看到人类对那个时代的渴望
## 但是远远不够

Jev最近很火 不是像gpt6、fable5一样 以压倒性的强大而出名 

而是以一种新的方式 他们称他为**System 1 decision engine**

简单来说 就是 不再让模型生成token 一个字一个字的预测生成

而是 **并行的直接生成json**

```
json`
{

"A":{
"noul": 0.9
  }
}
```

灵感的来源是 诺贝尔奖得主的《思考---快与慢》这本书

所以**系统一** 可以理解成直觉 比如你在日常生活中 一瞬间就能感知到某种情绪 比如环境的压抑 别人情绪的低落

那么**系统二** 也就是现在的大模型 就是人类生活中那些推理 思考的部分

那么他的优势就显而易见了 在决策和判断中 具有压倒性的速度优势与成本优势

这也很好理解 一个从小到大都被喊来训练口算加减题的人 在给他一本口算题卡的时候 计算的速度肯定能够轻松的碾压那些行业的魁首

所以 重点在于 Jev根本没有脱离所谓的Transformer的架构 只不过在训练和其中的某些部件上（Decoder）做了改动

## 那么重点来了 既然没有所谓的架构性上的创新 为什么他会成为这几周来火爆全世界的模型呢？ 我又为什么会说他是一个“值得称赞的挣扎呢”

探讨这个问题前 我们先看一下 jev到底能做到什么 

简单概括 就三种

1. 选择题
2. 判断题
3. 打分题

选择题 就是给你几个选项 让你选出概率最高的那个

那么问题来了 这不就是传统的llm吗 你让他输出json格式的各个选项的可能性 达成的效果不是一样 有什么区别

没错 llm也能做到 但是关键在于底层

llm的预测 本质还是 依靠自回归 一个一个token的预测 预测结束后 对最终输出的结果做格式化（json）处理 

jev则是 他固定好要输出的就是 比如给出A:__,B:__,c:__....然后直接输出概率之后填空 这是一个并行的过程

实际上他的功能非常好理解

那判断题和打分题就更好理解了 

判断题只需要输出某件事的可能性 然后你来设置阈值 如果可能性大于某个值 那么就是yes 否则就是no

打分题其实同上 只是你可以提前预设几个等级 比如你设定某件事的紧急程度是 1级，2级，3级 那么jev就能在极短的时间内告诉你紧急程度

那么讲完了jev实际能做的 你应该也能立马反应到 这不就是一个决策专精的大模型吗

是的 你的概括非常准确
