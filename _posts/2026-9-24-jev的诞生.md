# Jev：一次值得赞颂的挣扎，我能看到人类对那个时代的渴望

### 但是远远不够

Jev 最近很火。

但它的火，并不是像 GPT-6、Fable 5.1 那样，以一种近乎蛮横的强大出名。

它没有试图成为最聪明的聊天机器人。

没有试图成为最强的推理模型。

甚至没有试图成为一个“什么都会”的 AI。

相反，它给自己取了一个很奇怪的名字：

**System One Decision Engine。**

翻译过来就是：

# **系统一。**

这个名字让我一下想到了诺贝尔经济学奖得主 Daniel Kahneman 的《思考，快与慢》。

Kahneman 把人的思维粗略分成两个系统：

**System 1：快速、自动、直觉式。**

**System 2：缓慢、刻意、需要思考。**

TypeSafe 也明确表示，Jev 的 System One 命名正是受到这个思想的启发。

所以，如果借用人类的比喻：

### System 1，可以理解为直觉。

比如你走进一间教室。

你甚至不需要思考，就能感觉到：

这里很压抑。

那个人今天情绪不太好。

这件事情有点不对劲。

这些事情发生得太快了。

快到你甚至来不及告诉自己：

> “现在让我进行一次完整的逻辑推理。”

它就是发生了。

---

### System 2，则更像我们现在熟悉的大模型。

看到一道复杂的数学题。

分析一篇论文。

写一段代码。

规划一个 Agent。

拆解一个任务。

这些事情，都需要：

**推理。**

**分析。**

**思考。**

**一步一步来。**

而过去这几年，我们几乎把 AI 的全部希望，都压在了 System 2 上。

更大的模型。

更多的参数。

更长的上下文。

更强的 reasoning。

让模型想得越来越久。

越来越深。

越来越复杂。

可是 Jev 突然换了一个问题：

> **AI 有没有必要每一次都思考？**

---

# 有些决定，根本不值得思考

想象一下。

一个 GUI Agent 正在操作电脑。

它已经看懂了当前的页面。

已经知道自己要搜索什么。

现在屏幕上有三个按钮：

```text
A：Search
B：Login
C：Back
```

传统的大模型可能会：

看图。

理解页面。

分析任务。

思考上下文。

生成 reasoning。

再生成：

```text
The next action should be clicking Search...
```

然后程序再把这一串文字解析回来。

最后：

**Click(A)。**

为了点击一个按钮，

一个拥有几十亿甚至数百亿参数的大脑，

完整思考了一遍。

这合理吗？

其实不太合理。

因为这时候我们需要的根本不是思考。

我们需要的只是：

> **决定。**

---

# 所以 Jev 做了一件很奇怪的事情

它放弃了传统大模型最擅长的东西：

**文字。**

不再一个 token 一个 token 地生成：

```text
我
认
为
下
一
步
应
该
...
```

而是直接面对一个已经定义好的决策空间。

例如：

```text
A：0.03
B：0.92
C：0.05
```

直接给出结果。

没有废话。

没有长篇 reasoning。

没有额外的字符串。

只有：

**概率。**

TypeSafe 对 Jev 的公开描述也是如此：输入非结构化 state，输出预先定义好的 typed decisions、probabilities 和 confidence，并采用并行采样，而不是逐 token 自回归生成。

这就有点像：

> **以前的 AI 在考试答题。**

而 Jev：

> **直接填答题卡。**

---

# 那么它到底会做什么？

其实非常简单。

简单到甚至有点可笑。

概括起来，就三种。

```text
1. 选择
2. 判断
3. 打分
```

### 选择

给你几个选项。

问：

> 这个任务应该交给谁？

```text
Billing     0.91
Technical   0.06
Sales       0.03
```

Jev 不需要写一篇分析。

直接：

> Billing。

---

### 判断

问：

> 这个邮件是不是诈骗？

直接得到：

```text
P(True) = 0.93
```

你甚至可以自己设置阈值。

如果：

```text
P > 0.8
```

那么：

**YES。**

否则：

**NO。**

---

### 打分

比如：

> 当前任务完成度是多少？

或者：

> 这个请求有多紧急？

返回：

```text
0
1
2
3
```

以及每一个等级对应的概率。

这就是所谓的：

**Choice / Noul / Score。**

Jev 官方把这些结构化决策作为 System One 的核心使用方式。

---

# 可问题来了

### 这不就是传统 LLM 能做的吗？

当然是。

你让 GPT、Claude、DeepSeek 输出：

```json
{
  "A": 0.9,
  "B": 0.08,
  "C": 0.02
}
```

它当然也能做到。

所以 Jev 真正有意思的地方，

根本不是：

> **“别人不会做这个，只有我会。”**

恰恰相反。

### 大模型当然会。

但问题在于：

**底层是完全不同的。**

传统 LLM 本质上还是在做：

```text
token
 ↓
token
 ↓
token
 ↓
token
 ↓
JSON
```

即使最后输出一个漂亮的 JSON，

它依然是：

**先生成。**

然后：

**再格式化。**

而 Jev 从一开始就不是为了生成字符串设计的。

它面对的是一个**固定类型的决策空间**。

所以它不是在说：

> “让我生成一句话，告诉你答案。”

而是在做：

> “我直接告诉你答案的概率分布。”

TypeSafe 官方把两者的差异概括得非常直接：LLM 是 sequential sampling，一次生成一个 token；Jev 则采用 parallel sampling，一次查询直接得到所有决策输出。

---

# 这就是它真正的优势

**速度。**

**成本。**

更重要的是：

**确定性。**

一个从小到大，

天天被拿去训练口算加减的人，

当你真的给他一本口算题卡的时候，

你当然不能说：

> “他的智商一定比那些顶级数学家高。”

可是你完全可以说：

> **如果只比口算，他就是专精。**

这就是 Jev。

它不是比 GPT 更聪明。

甚至也不是比 GPT 更全能。

它只是：

# **把“决策”这件事情做到了极致。**

---

# 所以我越来越喜欢一句话

### **它不是一脚踢开 GPT 单干的全能，而是在决策上登峰造极的专才。**

这句话其实比：

> “Jev 很快。”

更加重要。

因为速度只是结果。

**专精才是原因。**

---

# 这对 GUI-Agent 意味着什么？

如果你研究过 GUI Agent，

你应该很容易理解。

以前一个视觉 Agent 玩游戏的时候：

```text
截图
↓
VLM 理解画面
↓
判断当前情况
↓
规划下一步
↓
思考调用什么工具
↓
执行
↓
再次截图
```

每一步，

大模型都要重新思考一遍。

而 Jev 可以被放在中间：

```text
VLM
 ↓
理解当前环境
 ↓
产生候选动作
 ↓
Jev
 ↓
选择动作
 ↓
Executor
 ↓
游戏
```

比如当前有：

```text
Attack
Heal
Run
Open Inventory
```

VLM 已经知道：

> “现在需要治疗。”

那么 Jev 不需要再重新理解整个世界。

它只需要：

```text
Attack        0.03
Heal          0.94
Run           0.02
Inventory     0.01
```

然后：

**Heal。**

结束。

这就是它最让我兴奋的地方。

---

# 因为我突然发现

我们过去似乎一直在犯一个错误。

我们总想着：

> **让一个模型什么都会。**

会聊天。

会写代码。

会数学。

会视觉。

会规划。

会记忆。

会操作电脑。

会玩游戏。

会做科研。

最后甚至希望：

> **会成为 AGI。**

可是现实世界里的智能，

真的一定要这样吗？

人类自己都不是这样。

医生不会要求自己成为最好的钢琴家。

程序员不会要求自己同时成为世界冠军运动员。

数学家也不需要每天负责修发动机。

**人类文明本身，就是建立在分工上的。**

---

# 所以我真正感兴趣的，不是 Jev

而是：

# **专精。**

Transformer 太成功了。

成功到今天几乎没有人不知道它。

也成功到整个 AI 世界已经形成了一种非常强烈的路径依赖：

> **模型不够强？**

加参数。

> **推理不够强？**

加 reasoning。

> **效果不够好？**

加数据。

> **速度不够快？**

加硬件。

我们似乎一直在问：

> **怎么把同一个模型变得更强？**

而 Jev 让我第一次开始思考另一个问题：

> **为什么一定要让同一个模型什么都会？**

也许未来的 AI，

根本不是一个巨大的模型。

而是一群彼此协作的专才。

---

# 一个模型负责看

它可以用最快的速度分析一张图片。

识别布局。

理解空间关系。

找到按钮。

---

# 一个模型负责想

它拥有庞大的知识。

负责复杂 reasoning。

负责制定长期计划。

负责面对完全陌生的问题。

---

# 一个模型负责记

记录历史。

建立长期记忆。

知道过去发生了什么。

---

# 然后

### 让 Jev 负责选择。

在无数个已经存在的可能性里面，

毫不犹豫地：

**选一个。**

这时候，

AI 就不再像一个人。

它更像：

> **一个社会。**

每一个模型都是一个专业的人。

而 Harness，

负责让他们彼此协作。

---

# 也许这才是 Agent 真正有意思的地方

以前我们总觉得：

> Agent = 一个大模型 + 一堆工具。

可是现在越来越不像了。

它可能变成：

```text
Perception
      ↓
Planning
      ↓
Memory
      ↓
Decision
      ↓
Execution
      ↓
Verification
```

不同模块，

甚至可以由不同的模型完成。

大模型负责：

**为什么。**

Jev 负责：

**选哪个。**

Executor 负责：

**怎么做。**

Verifier 负责：

**做对了吗。**

而 Harness 负责：

**什么时候让谁出来。**

这时候，

Agent 就不再是一个模型。

而是一套系统。

---

# 所以，为什么我把 Jev 称作“一次值得赞颂的挣扎”？

因为它其实还没有证明自己能够颠覆什么。

它没有创造一个全新的宇宙。

没有发明一个比 Transformer 高一个维度的神经网络。

甚至从公开信息来看，我们现在还不能说 Jev 已经证明了一个全新的底层架构范式；TypeSafe 只公开说它采用了新的模型架构、parallel sampler 和 RLCD，具体内部架构仍没有完全公开。

可是，

**我依然想赞颂它。**

因为我看到的不是结果。

而是：

### **挣扎。**

Transformer 太好用了。

好用到我们甚至很难想象：

> **下一个时代的模型到底应该长什么样。**

于是人类开始换一种办法。

既然无法立刻摆脱 Transformer，

那就先摆脱：

**“一个模型必须什么都会”的思想。**

不再追求全能。

开始追求专精。

不再追求生成一切。

开始追求直接决策。

不再让一个巨大的模型完成所有事情。

开始让很多模型各自做好自己的那一件事情。

---

# Laya 的出现，让这件事情更有意思了

其实我最开始认识这一方向，

反而是从最近开源的 Laya 开始的。

一开始我甚至以为：

> **Laya 才是后来者。**

毕竟 Jev 的背后有 TypeSafe，

而 TypeSafe 的创始人 Diogo Almeida 此前参与过 OpenAI 的相关研究。

这让我下意识觉得：

> “这种东西怎么可能是后来才有人想到的？”

可当我后来看到 Laya 作者自己写出来的文章，

才发现：

**事情可能远没有这么简单。**

Laya 作者声称，他们早在 2025 年就已经在做非自回归决策模型，并且后来进一步提出了 RLCD 的框架；而 Laya 如今则明确开源成了一个 421M 参数、基于 ModernBERT Encoder 的 System 1 Decision Model。

更有意思的是，

双方现在对这个方向的叙述，

竟然高度相似：

```text
Non-autoregressive
↓
Decision
↓
Probability
↓
Calibration
↓
RLCD
↓
System 1
```

于是我第一次意识到：

### **一个真正重要的方向，往往不是一个人突然想出来的。**

可能在不同的地方，

已经有很多人，

同时摸到了那扇门。

有人更早。

有人做得更漂亮。

有人拥有更多资金。

有人更擅长把它推向世界。

这才是科研最有意思的地方。

---

# 但我依然觉得

### **远远不够。**

因为 Jev 解决的是：

> **“如何更快地做决定。”**

而我们真正缺少的，

也许仍然是：

> **“什么才是智能？”**

我们可以把模型变得更快。

更便宜。

更专业。

甚至让几十个模型彼此协作。

可是：

**这依然不等于 AGI。**

甚至可能离 AGI 还非常遥远。

但这并不重要。

因为科技从来不是一步跳到终点。

蒸汽机不会直接变成火箭。

第一台计算机也不会直接变成今天的 AI。

真正重要的，

往往是那个时代开始出现一些：

**看起来还不够伟大，

却和过去不太一样的东西。**

---

# 我不知道 Jev 会不会成为下一个时代的答案

也许不会。

也许几年以后，

System 1 只是 AI 历史中的一个注脚。

也许 Transformer 还会继续统治十年。

也许真正的下一次革命，

仍然会来自我们现在完全不知道的某个角落。

可是至少，

Jev 让我看到了一件我很久没有看到的东西：

> **人类开始尝试停止把所有希望押在“更大”上。**

开始追求：

**更快。**

**更专。**

**更协同。**

开始承认：

> 一个模型不需要什么都会。

也许未来真正强大的 AI，

从来就不是一个无所不能的神。

而是一群彼此协作的专家。

---

### 我不知道那个时代什么时候会来。

### 但至少，我已经能看到有人在朝那里走了。

**这一次，他们没有继续把模型做得更大。**

**他们开始尝试让它只做一件事。**

### 这是一场值得赞颂的挣扎。

### 但是远远不够。
