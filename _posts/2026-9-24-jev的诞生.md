# Jev——一次值得赞颂的挣扎，我能看到人类对那个时代的渴望
### 但是远远不够

Jev最近很火 不是像gpt6、fable5一样 以压倒性的强大而出名 

而是以一种新的方式 他们称他为**System 1 decision engine**

简单来说 就是 不再让模型生成token 一个字一个字的预测生成

而是 **并行的直接生成json**

```
json`
{

"A":{
"noul": 0.9
  }
}
```

灵感的来源是 诺贝尔奖得主的《思考---快与慢》这本书

<img width="580" height="586" alt="image" src="https://github.com/user-attachments/assets/8408ccdd-2771-4633-929f-e4270f88b3cf" />

### 所以**系统一** 可以理解成直觉 比如你在日常生活中 一瞬间就能感知到某种情绪 比如环境的压抑 别人情绪的低落

### 那么**系统二** 也就是现在的大模型 就是人类生活中那些推理 思考的部分

那么他的优势就显而易见了 在决策和判断中 具有**压倒性的速度优势与成本优势**

这也很好理解 *一个从小到大都被喊来训练口算加减题的人 在给他一本口算题卡的时候 计算的速度肯定能够轻松的碾压那些行业的魁首*

所以 重点在于 Jev根本没有脱离所谓的Transformer的架构 只不过在训练和其中的某些部件上（Decoder）做了改动

## 那么重点来了 既然没有所谓的架构性上的创新 为什么他会成为这几周来火爆全世界的模型呢？ 

我又为什么会说他是一个“值得称赞的挣扎呢”

探讨这个问题前 我们先看一下 jev到底能做到什么 

# 简单概括 就三种
```
1. 选择题
2. 判断题
3. 打分题
```

<img width="1569" height="618" alt="image" src="https://github.com/user-attachments/assets/d3b21ac3-4a4b-49fa-8451-d010d1a72006" />

### 选择题 就是给你几个选项 让你选出概率最高的那个

那么问题来了 这不就是传统的llm吗 你让他输出json格式的各个选项的可能性 达成的效果不是一样 有什么区别

没错 llm也能做到 但是关键在于底层

llm的预测 本质还是 依靠自回归 一个一个token的预测 预测结束后 对最终输出的结果做格式化（json）处理 

**jev**则是 他固定好要输出的就是 

比如给出
```
A:__,B:__,c:__....
```
然后直接输出概率之后填空   
这是一个并行的过程

实际上他的功能非常好理解

那**判断题和打分题**就更好理解了 

判断题只需要输出某件事的可能性 然后你来设置阈值 如果可能性大于某个值 那么就是yes 否则就是no

那么讲完了jev实际能做的 你应该也能立马反应到 这不就是一个决策专精的大模型吗

是的 你的概括非常准确

一个简单但又十分正确的暴论

## Jev能做的 Kimi deepseek gpt claude甚至腾讯元宝都能做

他真正的优势在于 **专精**

举个例子 曾经我们用视觉模型来玩mc VLM需要先截取当前截图 然后分析当前状况 再让LLM做规划 并且思考调用什么工具 每一步都要思考 每一步都要推理 这太慢了

Jev则可以做到 VLM分析完当前的状况后 直接在可备选的工具中 秒选出需要的工具

对 他不是一种一脚踢开GPT单干的全能 但却是在决策上登峰造极的人才

<img width="1100" height="630" alt="image" src="https://github.com/user-attachments/assets/ef5c362e-956a-4ec3-9596-524f01e33f7b" />

其实如果你玩过游戏 就应该很清楚 一个能在毫秒级决定使用工具的AI 能在游戏上取得什么样的成绩

所以 问题回到我一开始说的 为什么我认为他是一次漂亮的挣扎呢

因为 **transformer**太好用了 好用到没有人能预测 下一个颠覆性的架构 什么时候会到来

但是为了那个时代 人类想出了另一条路

# **专精**

他真正让我惊讶的 不是这样的一个模型 能造成多大的影响 给AI界带来多大的震荡

我想到的 是未来的AI 也许会趋向专精

现在是一个语言模型 可能又要解决数学问题 又要判断图中人物的特征 又要负责帮人解决情感问题 

将来的设想可能是 某类模型 可以最快速度的分析一张图片的布局 然后大模型 做规划 然后jev做选择 将完成某种任务的时间压缩到机制

也许这不是AGI 但是如果在这样的组合拼凑下 人类的科研水平可能达到一个前所未有的高度

那么AGi的到来 会不会以某种人们未曾设想过的时间降临呢？
